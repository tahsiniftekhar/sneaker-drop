# Sneaker Drop frontend

React + TypeScript + Vite single-page app. See the [root README](../README.md) for the full setup.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
```

Environment variables (optional; defaults point at a local backend):

- `VITE_API_URL`: REST API base URL (default `http://localhost:5000/api`)
- `VITE_SOCKET_URL`: Socket.io server URL (default `http://localhost:5000`)
